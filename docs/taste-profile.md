## T1 一键模板庆祝（CapCut / 剪映模板）
- **为什么传播**：生日、毕业、升职这类人生节点本来就要发；模板给了「大片感」（大字标题 + 烟花 / 香槟喷泉 + 卡点音乐），自己拍一张就能出片。截图里分享（9,539）接近赞（15.3K）的 60%，说明大家在转发模板给朋友。
- **二创机制**：「Try this template」按钮，换照片 / 视频即可；同一模板下成千上万条。
- **产品迁移**：直播间 / 私信的「节日模板」：生日当天好友一键生成祝福视频；直播间生日特效 + 礼物联动；模板作者激励（CapCut Pioneer 式的模板创作者计划）。
- **怎么找**：`#capcut` `#capcutpioneer` `#birthdaytrend` `#happybirthdaytome`、CapCut 模板榜、音频 It's Raining Men；搜「template + birthday / graduation / new year」。

## T2 POV 反应梗 × 品牌 / 体育
- **为什么传播**：「POV: X 想起 Y 的时候」+ 夸张表情，粉丝圈（F1、球队、明星）内部梗，外人也看得懂情绪；品牌 / 车队官方号下场更有反差。
- **二创机制**：固定字幕句式「POV: … cuando / when …」，换主角和处境；同一张反应画面被剪成表情包。
- **产品迁移**：赛事 / 节点直播间的「反应镜头」一键生成可分享片段；粉丝社群的 POV 字幕模板；评论区可插入的反应 GIF。
- **怎么找**：`POV` + 赛事名（`#F1` `#Cadillac F1` `#NBA` `#WorldCup`），车队 / 球队周边店和官方号；临近大赛（GP、决赛）前一周搜。

## T3 AI 怪诞角色 × 怀旧老歌
- **为什么传播**：一眼「不对劲」的 AI 角色（夸张身材、复古泳装、假老电影质感）配大家都会唱的老歌（意大利金曲、80 年代假声），反差 + 怀旧 + 「这是真的吗」。
- **二创机制**：同一音频 + 同一种画风，换场景 / 角色；AI 视频工具（Higgsfield、Kling、Veo 等）几分钟复刻。
- **产品迁移**：「老歌 + 画风」组合的 AI 短片模板；直播间怀旧金曲时段的 AI 角色伴舞特效；AI 标识与「这是真的吗」引导。
- **怎么找**：音频 `Sarà perché ti amo` `Smalltown Boy` 等老歌 + `#aivideo` `#aiart` `#surreal` `#uncanny`；Jump on the Trend 的 AI 趋势页；Know Your Meme 的「AI-generated」标签。

## T4 宠物 / AI 萌宠做人类编舞
- **为什么传播**：可爱 × 拟人；宠物站 C 位、人类做伴舞，或宠物唱人类情歌，不需要语言，全球通吃（King Odie：5.7M 赞、1.2M 分享）。
- **二创机制**：「宠物照片 + 参考舞蹈 / 歌曲」AI 动作迁移；或真宠物 + 人类伴舞翻拍。
- **产品迁移**：「上传宠物照片 + 选一支舞 / 一首歌」模板；直播间宠物主播的同款挑战；好友宠物合拍。
- **怎么找**：`#dachshund` `#dogsoftiktok` `#catsoftiktok` `#aipet` `#aicat` + 热门舞曲 / 情歌；Jump on the Trend `/trends/pets/`。

## T5 走秀 / 角色走路
- **为什么传播**：夸张或怪诞的造型 + 一条「T 台」直线（练舞室、走廊、停车场），几秒看完，适合循环播放；截图里 297.2K 分享接近 373.7K 赞，说明被大量转发。
- **二创机制**：固定镜头和走位，换造型 / 角色 / 宠物；变装版（低机位抬镜头）。
- **产品迁移**：直播间「走秀模式」特效（灯光、计分、观众打分）；虚拟换装 + 走秀分享；电商试穿。
- **怎么找**：`#runway` `#runwaywalk` `#fashionshow` `#mogging` `#walk`、截图里的 `#BalliBotMogis`（含义待查）；练舞室 / 走廊走秀视频。

## T6 名场面台词 / 角色化 二创
- **为什么传播**：全网都认得的一句台词、一个名场面或一个角色形象（大长今问汤、AI 模型拟人、私人领地、街头即兴），固定的部分让人秒懂，替换的部分制造新笑点。
- **二创机制**：固定台词 / 构图 / 动作，替换答案、主角或世界；角色化的会长出同人剧情和翻唱。
- **产品迁移**：「名台词接龙」评论区玩法、连麦对戏；给 AI 助手 / 虚拟主播捏形象和人设；「把自己放进名场面」模板。
- **怎么找**：Know Your Meme 新词条；B站热门「废话文学 / 名场面 / 拟人」；TikTok `#recreation` `#reenactment` `#remake`；Jump on the Trend 的 AI remake 页。

## T7 一个动作 + 一个道具
- **为什么传播**：门槛只有一个动作和一个家里就有的道具（风扇叶片遮剪辑点、甩水瓶出水花），机关一眼看懂，人人想试。
- **二创机制**：换衣服 / 换道具 / 换场地；明星官方挑战带动。
- **产品迁移**：直播间的「转场换装」「道具轨迹」特效，绑定礼物或试穿；挑战 PK。
- **怎么找**：`#transition` `#outfittransition` `#dancechallenge` + K-pop / 新歌名；Lightreel、Ramdam 周报。

## T8 一句字幕的处境梗
- **为什么传播**：画面固定、字幕写一个人人都有的处境（被点醒、笑着崩溃、坦白、反转），零表演门槛。
- **二创机制**：同一音频换字幕和场景即可。
- **产品迁移**：「梗字幕」创作入口（选音频 → 填一句处境）；好友接力话题。
- **怎么找**：Ramdam、newengen 的 TikTok 音频榜；`#relatable` `#pov` + 音频名。

## 不要的类型（对照 curation-rules）
一次性单条（开箱、品牌 Short、长视频挑战）、明星采访片段（无经典梗或表演）、生活 / 育儿技巧、伤害性玩法、只有原作者自己在发的系列。
